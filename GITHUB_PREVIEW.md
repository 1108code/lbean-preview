# Let's Bean Coffee - GitHub Preview Package

This folder is ready to upload to GitHub.

## Preview Locally

```bash
npm install
npm run dev
```

Open:

```text
http://localhost:3000/
http://localhost:3000/cms
```

## Deploy On Netlify

Use these settings:

```text
Build command: npm run build:netlify
Publish directory: netlify-dist
Environment variable: CMS_PASSWORD=yourpassword
```

The website is at `/` and the CMS is at `/cms`.
